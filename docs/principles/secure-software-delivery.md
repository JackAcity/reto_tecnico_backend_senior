# Principio: entrega segura de software

**ENGINEERING DECISION:** una entrega es segura solo en la medida en que puede relacionar intención, cambio, verificación, artefacto, autorización, runtime y recuperación. La velocidad no justifica eliminar un eslabón; el perfil de riesgo determina la profundidad del control.

Este principio se concreta en CTL-001 a CTL-013 y se apoya en SSDF v1.1 como marco de recomendaciones. No declara conformidad SSDF.
