# Principio: mainline y lotes pequeños

**ENGINEERING DECISION:** una rama de integración confiable debe mantenerse desplegable mediante cambios pequeños, revisables y frecuentes. Este es un patrón de trabajo propuesto, no un requisito de NIST, SLSA ni DORA por sí mismo.

La variante concreta —trunk directo, `develop` o release branches— depende de riesgo, cadencia y compatibilidad. **TBD-SCM-01:** aprobar el modelo de ramas antes de activar CTL-001.
