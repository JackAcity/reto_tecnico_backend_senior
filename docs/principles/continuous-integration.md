# Principio: integración continua

**RESEARCH EVIDENCE:** DORA asocia testing continuo con capacidad de entrega. **ENGINEERING DECISION:** los cambios pequeños e integrables deben recibir feedback automatizado desde una definición versionada antes de integrarse.

CI no equivale a “tener un workflow”: requiere inputs identificables, resultado conservado, pruebas pertinentes y un gate cuya efectividad se haya evaluado. CTL-002 y CTL-003 lo modelan.
