# Principio: seguridad integrada y proporcional

**ENGINEERING DECISION:** seguridad participa desde el diseño de control, no aparece como un escaneo tardío. Cada control debe declarar riesgo, coste, fallo, verificación, evidencia, dueño y excepción.

DevSecOps no significa activar todas las integraciones disponibles. Un control se implementa solo si su riesgo, aplicabilidad y verificación justifican el coste para el perfil correspondiente.
