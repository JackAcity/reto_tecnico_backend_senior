# Principio: entrega continua

**RESEARCH EVIDENCE:** DORA describe entrega continua como una práctica que busca reducir riesgo; no obliga a despliegue automático. **ENGINEERING DECISION:** el sistema debe poder promover un artefacto ya verificado por digest hasta un destino autorizado, con una decisión explícita por riesgo.

El despliegue automático a producción no se presupone. CTL-009, CTL-010 y CTL-011 exigen identidad, autorización y recuperación antes de diseñar un adaptador.
