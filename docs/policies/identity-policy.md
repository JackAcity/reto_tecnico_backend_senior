# Política propuesta: identidad

Estado: **propuesta; requiere aprobación humana**.

Las identidades humanas, de agente, CI, GitHub App y cloud se separan por función. Cada una recibe privilegio mínimo, duración limitada y evidencia de uso. Para cloud se prefiere federación OIDC condicionada sobre secretos de larga duración. Implementa conceptualmente CTL-007, CTL-010 y CTL-012.
